# 硬件安全

本部分探讨现代处理器和计算系统中的安全威胁、攻击方法和防护技术。

## 概述

硬件安全涉及处理器微架构、侧信道攻击、推测执行漏洞等多个层面。随着处理器性能优化技术的发展，新的安全威胁不断涌现，需要深入理解硬件机制才能有效防护。

## 主要内容

### 推测执行攻击

利用现代处理器推测执行机制的安全漏洞。

## 核心概念

### 微架构安全

- **推测执行**: 分支预测和乱序执行带来的安全风险
- **缓存侧信道**: 通过缓存访问模式泄露信息
- **时序攻击**: 利用执行时间差异获取敏感信息

### 攻击分类

- **Spectre 类攻击**: 利用推测执行的边界检查绕过
- **Meltdown 类攻击**: 利用乱序执行的权限检查绕过
- **缓存攻击**: Flush+Reload、Prime+Probe 等技术

### 防护机制

- **硬件缓解**: 微码更新、硬件修改
- **软件缓解**: 编译器防护、操作系统补丁
- **架构设计**: 安全优先的处理器设计

### 性能与安全平衡

- **缓解措施成本**: 安全补丁对性能的影响
- **设计权衡**: 安全性与性能的平衡考虑
- **未来趋势**: 安全感知的处理器架构
