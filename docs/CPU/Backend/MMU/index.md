# Rocket Chip 内存管理单元 (MMU)

## 概述

Rocket Chip 的内存管理单元（Memory Management Unit, MMU）是一个完整的虚拟内存系统实现，严格遵循 RISC-V 特权级架构规范。MMU 为现代操作系统提供了必要的内存保护、地址转换和进程隔离功能，是支持 Linux 等复杂操作系统在 RISC-V 硬件上运行的关键组件。

## 设计理念

Rocket Chip MMU 的设计体现了以下核心理念：

- **架构合规性**： 严格遵循 RISC-V 特权级架构规范，确保软件兼容性
- **模块化设计**： 组件间通过标准化接口交互，支持不同核心复用
- **高度可配置**： 通过参数化设计支持广泛的应用场景
- **性能优化**： 在保证功能正确性的基础上优化性能和功耗

## 系统架构

### 整体组织结构

```
┌─────────────┐    ┌─────────────┐
│   I-TLB     │    │   D-TLB     │
│  (指令TLB)   │    │  (数据TLB)   │
└──────┬──────┘    └──────┬──────┘
       │                  │
       └─────────┬────────┘
                 │
         ┌───────▼───────┐
         │   L2 TLB      │
         │  (可选共享)    │
         └───────┬───────┘
                 │
         ┌───────▼───────┐
         │      PTW      │
         │  (页表遍历器)  │
         └───────┬───────┘
                 │
         ┌───────▼───────┐
         │ Memory System │
         │  (缓存层次)    │
         └───────────────┘
```

### 关键组件

1. **Translation Lookaside Buffer (TLB)**： 高速地址转换缓存
2. **Page Table Walker (PTW)**： 硬件页表遍历器  
3. **Control and Status Registers**： 控制和状态寄存器
4. **Synchronization Logic**： 同步和一致性维护逻辑

## 主要特性

### 架构兼容性

- **RISC-V 特权级规范**： 完全符合 RISC-V Privileged Architecture
- **Sv39/Sv48 支持**： 支持 39 位和 48 位虚拟地址空间
- **Linux 兼容**： 原生支持 Linux 内核的内存管理

### 性能特性

- **多级 TLB**： L1/L2 TLB 层次结构优化命中率
- **超级页支持**： 4KiB/2MiB/1GiB 页面大小
- **ASID 优化**： 避免上下文切换时的 TLB 刷新
- **硬件页表遍历**： 自动化的多级页表查找

### 可配置选项

| 参数 | 描述 | 配置范围 |
|------|------|----------|
| nTLBSets | L1 TLB 组数 | 1-64 |
| nTLBWays | L1 TLB 相联度 | 1-8 |
| nL2TLBSets | L2 TLB 组数 | 1-128 |
| nL2TLBWays | L2 TLB 相联度 | 1-16 |
| nTLBSuperpages | 超级页支持级别 | 0-2 |

## 性能评估

### 关键性能指标

- **TLB 命中率**： 通常达到 95% 以上
- **页表遍历延迟**： 典型情况下 10-50 个时钟周期
- **SFENCE.VMA 开销**： 1-10 个时钟周期
- **上下文切换开销**： 通过 ASID 优化显著降低

### 性能优化建议

1. **TLB 配置优化**： 根据应用特性调整 TLB 大小和相联度
2. **超级页使用**： 利用大页面减少 TLB 压力
3. **ASID 管理**： 合理分配和回收 ASID
4. **页面布局**： 优化虚拟地址空间布局
