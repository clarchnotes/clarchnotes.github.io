# RISC-V 指令集架构

## 概述

RISC-V 是一个开放的指令集架构，基于精简指令集计算 (RISC) 原理设计。其模块化和可扩展的特性使其成为学术研究和工业应用的理想选择。

## 核心概念

### ISA 设计原理

- **模块化设计**: 基础指令集 + 可选扩展
- **简洁性**: 精简的指令集减少硬件复杂度
- **可扩展性**: 标准化的扩展机制

### 指令集组织

- **基础整数指令集**: RV32I/RV64I/RV128I
- **标准扩展**: M(乘除法)、A(原子操作)、F(单精度浮点)、D(双精度浮点)、C(压缩指令)
- **特权架构**: 机器模式、监管者模式、用户模式

### 浮点支持

- **IEEE 754 兼容**: 标准浮点格式和运算
- **多精度支持**: 单精度、双精度、半精度
- **软硬件协同**: 硬件加速 + 软件仿真

### 向量计算 (RVV)

- **可变长度向量**: 支持不同的向量长度配置
- **向量寄存器**: 32 个向量寄存器，每个可配置宽度
- **掩码和谓词**: 控制向量操作的元素选择
- **内存访问模式**: 单位步长、跨步、索引访问

### 内存模型

- **弱内存序**: 允许指令重排以提高性能
- **原子操作**: 支持多核同步
- **虚拟内存**: 页表机制和地址转换
